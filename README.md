# Röda Hönans rapportsystem
This web app is used for reporting the daily care of our chicken coop.

This template should help get you started developing with Vue 3 in Vite.

## Firebase firestore
The app uses Firebase for storing and authentication

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
